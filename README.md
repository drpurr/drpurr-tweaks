# drpurr-tweaks

A collection of small UI tweaks for **WoW Forever** (interface 16001). Each tweak has its own on/off toggle.

Settings: **Esc → Options → AddOns → drpurr-tweaks** (saved account-wide).

## Tweaks

### Action Bars
- **M4/M5 labels**: Mouse Button 4/5 keybinds shown as `M4`/`M5`.
- **Hide macro names**

### Swing Timer
- **Enable**: weapon label outside the bar; time centered. Position: Left / Right / Above / Below.

### Tooltip
- **Anchor to mouse**: Corner, Offset X/Y.
- **Skin**: BG, BG color, BG opacity, Border, Border color, Border opacity, Border size, Font, Font size, Outline.
- **Smart border**: border colored by item quality, reaction or class.
- **Inner health bar**: Height.
- **Fade out**: Time (0 = instant).
- **Spell IDs**: Spells, Auras.
- **Unit styling**: Name size, Guild brackets, Faction color, Name color, Class color, Level color, Short level, Target, Raid icon, Inline PvP, Hide titles, Hide realm, Real pet level.
- **Link icons**: icon beside chat-link tooltips.

### Bar Textures
- **Override**: Texture, Class health, Tooltip, Unit frames, Cast bars, Nameplates.

### Sound
- **Mute friend login**: silences the Battle.net friend-online toast.

## Install

Copy the `drpurr-tweaks` folder into `World of Warcraft/<client>/Interface/AddOns/`.

## Libraries

Embedded in `Libs/`: LibStub, CallbackHandler-1.0, LibSharedMedia-3.0.
